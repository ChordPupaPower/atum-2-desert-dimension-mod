Journey to Atum, a scorching desert dimension filled with pharaohs, mummies, and ancient ruins.

## Features

- Atum dimension: an endless desert realm
- Pyramid and Ruins structures with unique loot
- Pharaoh and Mummy boss mobs with unique drops
- New ores: Limestone, Ra's Scepter, and Nebu
- Ritual-based entry via a Sand Portal

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
